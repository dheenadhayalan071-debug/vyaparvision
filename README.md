# 🛒 VyaparVision
**ONDC & Bahi-Khata AI Bridge for Local Indian Retailers**
*Built for HACKDAY 1.0 (Tech for a Better Tomorrow)*

### The Problem
India's 12M+ Kirana stores rely on handwritten Bahi-Khata (ledgers) and struggle to digitize for ONDC or quick-commerce due to a lack of time and technical expertise.

### The Solution
VyaparVision uses Google Gemini Vision to instantly translate handwritten regional ledgers (Tamil/Hindi) into a structured digital catalog and WhatsApp-integrated checkout system. Zero typing required.

### Tech Stack
* **Frontend:** Next.js (App Router), Tailwind CSS, Recharts
* **AI Engine:** Google Gemini 2.5 Flash Vision API
* **Deployment:** Vercel
